# 🚗 Marketplace Automotivo - Frontend Web

## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de um **frontend para um marketplace automotivo**, inspirado em plataformas como a **webmotors**, criado como atividade da disciplina de **Acessibilidade Web** do **3º semestre** do curso de **Sistemas para Internet** da **FATEC**.

O objetivo principal é aplicar boas práticas de desenvolvimento front-end, acessibilidade e responsividade na construção de interfaces modernas e funcionais.

## 🎯 Objetivos do Projeto

- Desenvolver interfaces modernas para um marketplace automotivo;
- Aplicar conceitos de **HTML semântico**;
- Utilizar o framework **Bootstrap** para estruturação e estilização;
- Garantir **responsividade** em diferentes dispositivos;
- Implementar recursos de **acessibilidade** para leitores de tela;
- Seguir boas práticas de desenvolvimento web.

## ♿ Acessibilidade

Este projeto foi desenvolvido com foco em acessibilidade, buscando atender boas práticas para navegação inclusiva.

### Recursos aplicados:

- [x] Uso de HTML semântico;
- [x] Estrutura adequada de títulos e landmarks;
- [x] Compatibilidade com leitores de tela;
- [x] Navegação acessível;
- [x] Componentes responsivos utilizando Bootstrap;
- [x] Contraste e organização visual.
